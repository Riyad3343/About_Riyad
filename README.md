### 🚀 About Me

I am a backend-focused developer and digital service architect passionate about building fast, lightweight, and automated solutions. From engineering high-concurrency **Telegram bots** and **RESTful APIs** to managing Linux environments right from a terminal, I love turning complex workflows into clean, automated scripts.

- 💻 **Core Focus:** Python Backend Development, Custom Telegram Bots (`aiogram`, `Telethon`), & Web Scraping/Automation.
- 📱 **Workstation Philosophy:** Big fan of lightweight, terminal-centric development workflows (`Termux`, `SSH`, `Proot-Ubuntu`, and cloud PaaS).
- 🤖 **Current Exploration:** Integrating Large Language Model (LLM) APIs into terminal workflows and automated Telegram interfaces, alongside zero-knowledge auth concepts.
- 🎨 **Creative Side:** Photography, AI prompt engineering, kinetic typography, and 3D concept design.
